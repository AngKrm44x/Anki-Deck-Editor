# Editor Deck Anki

Offline GUI editor for Anki decks. Open, edit and export `.apkg`, CSV and TXT files without installing Anki.

**Features**
- Open `.apkg`, `.csv`, `.tsv`, `.txt`. Export to `.apkg`, Anki text, CSV and JSON
- Fast table with Anki-style search (`deck:`, `tag:`, `is:`, `re:` …)
- Rich field editor, cloze, HTML mode, card preview
- Decks and subdecks, tags, note types and templates, media manager
- Bulk move, tag, suspend and delete. Find & replace, duplicate and empty-card checks
- Undo/redo, dark mode, Indonesian and English
- Windows (installer and portable), Linux, macOS, Android 7.0+

All processing happens on your device. Nothing is uploaded.
